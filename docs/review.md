# レビューで維持する修正

Electron 版の [PR #1](https://github.com/yu-suke0919/atcoder-ruby-ide/pull/1) と
期待出力比較の [PR #2](https://github.com/yu-suke0919/atcoder-ruby-ide/pull/2) で確認した挙動を、Tauri 版でも維持する。
実装の共存や互換レイヤーは作らず、Rust の共通テストと実際の Windows 配布アプリで確認する。

| ID | 保持する修正 | 現在の検証 |
| --- | --- | --- |
| R01 | CRLF を含む解答ファイルを開いた直後に変更扱いにしない。エディターに代入した後の値を保存済みバッファにする | 作業領域の CRLF ファイルを開く GUI テスト |
| R02 | 一時ファイル削除が失敗しても実行中状態を解除する | Rust の RAII による予約解除、POSIX の権限変更テスト |
| R03 | 最小ウィンドウ・大きな行高でも入力と結果を 1 行以上表示し、実行ボタンに重ねない | Windows GUI のレイアウトテスト |
| R04 | 出力上限で切れた UTF-8 末尾を文字化けさせない。先に手動停止した場合も上限到達を独立して扱う | Rust の末尾デコード・停止と上限の重複テスト、GUI は最終出力に同期 |
| R05 | 未管理の Ruby フォルダーや破損したアーカイブを上書きしない | Node のアーカイブ整合性テスト |
| R06 | 保存は比較結果・実行中の比較を保持する | 自動保存・`Ctrl+S`・実行中の保存の GUI テスト |
| R07 | 画面再読み込みで保存中・保存失敗の変更を確認し、初期化時に実行をリセットする。初期化前の保存を別の問題の作業領域へ書かない | 共通 GUI の保存失敗時の再読み込み確認、実行中の初期化 |
| R08 | 期待出力・比較設定の編集で、未編集の標準入力や期待出力の改行を変えない | 共通 GUI の CRLF / CR ケースと実 Ruby のバイト列・JSON 保存 |

保存では比較の状態に触れないことで R06 を実現する。
ハッシュや保存イベントの世代番号など、同じ内容を表す別の状態は増やさない。
実行中に入力を編集した場合の判定無効化は、ケースごとの比較リビジョンで扱う。

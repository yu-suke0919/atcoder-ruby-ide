## 再現・修正した問題

| ID | 重要度 | 条件 | 修正 |
| --- | --- | --- | --- |
| R01 | P2 | CRLF の Ruby ファイルを開くと、textarea による LF 正規化と保存済みの文字列が一致しない | 保存済みの基準を実際の編集欄の文字列に合わせ、未編集のファイルを変更済みとして扱わない |
| R02 | P2 | Ruby が一時ディレクトリの権限を変更するなどして、実行後の削除に失敗する | 削除処理の成否によらず実行状態を解除し、後続のコードを実行できる |
| R03 | P2 | 最小画面の利用可能な高さが、入力・出力の固定最小高さの合計を下回るとパネルが実行ボタンに重なる | 利用可能な高さに応じて行とスクロール領域を縮める。行高を増やした Linux の再現条件と Windows CI で確認する |

それぞれ再現テストを追加し、修正前の失敗と修正後の成功を確認した。
Linux の共通テスト 21 件・画面テスト 12 件が成功し、失敗・スキップはない。
R02 の権限による再現は POSIX 専用のため Windows ではその 1 件のみスキップし、共通の実装で状態解除を保証する。

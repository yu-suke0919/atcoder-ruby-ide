# Rubyエディタ

CodeMirror 6を同梱し、Rubyコードの編集支援をオフラインで提供する。文書・保存先・未保存判定・実行の管理は既存の画面とRustバックエンドを使う。

- Rubyのキーワード・数値・文字列・コメントを色分けし、行番号とカーソル位置を表示する。
- 実行エラーの対象行を背景色で強調し、標準エラー欄からその行の先頭へ移動できる。コード変更や結果の失効で強調を解除する。詳細は[実行エラーからコードへ移動](run-errors.md)を参照する。
- 改行時はRubyの構造に応じて2スペースで字下げする。Tabはカーソル位置に2スペースを挿入し、複数行選択中は対象行を字下げする。Shift+Tabは対象行の字下げを解除する。Escの後のTabはフォーカス移動に使える。
- 丸括弧・角括弧・波括弧・引用符を補完し、対応する括弧を表示する。日本語変換中のキー操作を編集コマンドとして扱わない。
- Ctrl+Spaceまたは「補完」で候補を開く。入力による自動表示は行わない。上下キーで選択し、Enterまたはクリックで挿入、Escで閉じる。Tab／Shift+Tabは候補表示中・定型コード挿入後も既存の字下げ操作を維持する。
- 候補は同梱のRubyキーワード・よく使う標準メソッドと、現在の文書内の識別子形式の単語から作る。文書内候補はCodeMirrorの単語収集を使い、長い文書ではカーソル周辺を対象とする。宣言・スコープ・型の解析は行わず、コメントや文字列中の単語も収集対象となる。ドットの直後はメソッド候補を表示する。
- カーソルより前の文字で候補を絞り込み、確定時は識別子全体を置き換える。後続の `!=`・`!~` などの演算子は保持する。
- 定型コードは `if … end`、`items.each do |item| … end`、`gets.split.map(&:to_i)` の3種類。既存の字下げと2スペース単位を引き継ぎ、条件または対象の名前を選択してすぐ書き換えられる。ドットの後のeachは既存の対象を保持する。Tabによる入力欄の移動は設けない。
- コメント・文字列中と日本語変換中には候補を開かない。候補の表示・選択・取消だけでは未保存判定や比較結果を変えず、挿入は通常の編集として扱いUndo／Redoできる。ファイル操作で編集禁止になったら候補を閉じ、文書・問題の切替で前の文書の候補を残さない。
- 「検索・置換」またはCtrl+F／Ctrl+Hでエディタ内の検索・置換欄を開く。次／前の一致、個別／全件置換とEscでの終了に対応する。検索だけでは文書・比較結果を変更せず、置換は通常の編集として未保存・未比較にする。
- Ctrl+ZでUndo、Ctrl+YまたはCtrl+Shift+ZでRedoできる。Windowsでも両方のRedoキーを同じ編集履歴に適用する。別文書・新規作成・問題切替では履歴をリセットし、前の文書を復元しない。同じ文書の保存・問題文だけの更新は履歴を保つ。
- Ctrl+O・Ctrl+S・Ctrl+Shift+S・Ctrl+Enterは既存の開く・保存・名前を付けて保存・実行を優先する。ダイアログ内では既存の抑止を維持する。
- ファイル操作中・終了確認中はコードと置換による編集を禁止する。読み取り専用の間もフォーカスを受け取れ、問題を開いた後にコード欄へ戻れる。実行中の編集は既存どおり可能で、古い実行の比較結果を現在の入力へ反映しない。
- LFへの改行統一、UTF-8で1 MiBの読み込み・保存・実行上限、未保存保護、問題ごとの解答・ケース復元を維持する。900×650と問題文を含む3列配置でエディタ内をスクロールでき、検索欄で実行ボタンを押し出さない。検索欄も高さを制限し、収まらない操作は欄内でスクロールできる。
- JavaScriptとライセンスをビルド時に同梱する。CodeMirrorの表示用CSSはアプリ内で生成し、外部のスクリプト・フォント・サービスを取得しない。補完にRubyの実行や通信は使わず、型推論・LSPは対象外。

候補生成を単体テストで確認する。画面テストで色分け、字下げ、括弧補完・対応表示、入力補完・定型コード、検索・置換、Undo／Redo、履歴分離、日本語入力と未保存保護、保存・実行ショートカット、大きな文書・最小画面を確認する。LinuxのChromiumとWindowsのWebView2で共通の受入テストを実行する。

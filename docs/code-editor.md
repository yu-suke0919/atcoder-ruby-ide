# Rubyエディタ

CodeMirror 6を同梱し、Rubyコードの編集支援をオフラインで提供する。解答ファイル・自動保存・実行の管理は既存の画面とRustバックエンドを使う。

- Rubyのキーワード・数値・文字列・コメントを色分けし、行番号とカーソル位置を表示する。
- 実行エラーの対象行を背景色で強調し、標準エラー欄からその行の先頭へ移動できる。コード変更や結果の失効で強調を解除する。詳細は[実行エラーからコードへ移動](run-errors.md)を参照する。
- 改行時はRubyの構造に応じて2スペースで字下げする。Tabはカーソル位置に2スペースを挿入し、複数行選択中は対象行を字下げする。Shift+Tabは対象行の字下げを解除する。補完を表示していないときのEscの後のTabはフォーカス移動に使える。補完をEscで閉じた直後のTab／Shift+Tabは字下げ操作を維持する。
- 丸括弧・角括弧・波括弧・引用符を補完し、対応する括弧を表示する。日本語変換中のキー操作を編集コマンドとして扱わない。
- Ctrl+Spaceまたは「補完」で候補を開く。入力による自動表示は行わない。上下キーで選択し、Enterまたはクリックで挿入、Escで閉じる。Tab／Shift+Tabは候補表示中・定型コード挿入後も既存の字下げ操作を維持する。
- メソッドはLSPの候補を優先する。自作クラスの定義も未保存のまま補完に使う。既存の型推定・標準メソッドの説明は、LSPが候補を返さない場合の補完と日本語の概要に使う。以下の型推定の制約はこの基本補完に適用する。
- 基本候補は同梱のRubyキーワード・よく使う標準メソッドと、現在の文書内の識別子形式の単語から作る。文書内候補はCodeMirrorの単語収集を使い、長い文書ではカーソル周辺を対象とする。この単語収集は宣言・スコープを解析せず、コメントや文字列中の単語も対象となる。`.`・`&.`の直後はメソッド候補、範囲演算子`..`・`...`の直後は文書内単語・キーワード・標準メソッドなどの通常の候補を表示する。演算子の変更で補完の文脈が変わったら候補のキャッシュを失効させる。
- 引用符で閉じた単純な文字列、配列・ハッシュのリテラルを直接レシーバーにした式では、String・Array・Hashのよく使うメソッドに絞る。例は `"abc".up`、`[1, 2].ea`、`{a: 1}.ke`。括弧で囲んだ単一リテラルや `&.` にも対応する。文字列内の括弧とコメント内の括弧は構造に数えない。
- ローカル変数に文字列・配列・ハッシュのリテラルを直接代入した場合、その後の変数の`.`・`&.`でも型別の候補・引数説明を表示する。例は `text = "abc"` の後の `text.up`。同じ行の単純代入の右辺、自己再代入・連鎖代入の右辺、括弧や単純な呼び出し内でも使える（`ans = text.up`、`text = text.up`、`a = b = (text.up`、`ans = puts(text.up`）。右辺の補完には代入前の型を使い、完了した単純な再代入は新しい型へ切り替える。コメント・空行・セミコロン区切り・複数行の配列やハッシュに対応する。
- 変数の推定は単純な代入が続くコード区間を対象とする。代入以外の実行文、分岐・ループ・メソッドなどの境界、未知の値・複合代入・多重代入では以前の推定を解除する。境界の後に新たに直接代入した変数は推定できる。リテラル内の式が他の変数を変更し得る場合も以前の推定を解除する。別変数からの代入、戻り値、引数・ブロック引数の型は推定しない。
- 入力中の文が前の行から続く場合や、`def`・`undef`・`alias`によるメソッドの定義・操作中は変数の型で候補を絞らず、一般候補へ戻す。`return text.up`や`puts text.up`は通常どおり型別の候補を表示する。
- 添字による取得、シンボル、メソッドの戻り値、ブロック、補間記号（`#{`・`#@`・`#$`）がある二重引用符の文字列、%記法の文字列など、型を確定できない式は一般的なメソッド候補を表示する。リテラルの識別は直前最大4,096文字、括弧の展開は8段階までとする。変数の推定は文書先頭からレシーバーまで最大16,384文字を解析し、文区切りの入れ子は64段階までとする。上限超過・未完の複雑な式・ヒアドキュメントを含む区間・`__END__`以降では一般候補に戻す。代入内容・文脈が変わったら候補のキャッシュを再検証する。Rubyコードを実行して型を調べない。
- 対象の標準メソッド候補を選ぶと、候補詳細欄に引数・ブロックの形と短い日本語説明を表示する。標準型に応じて `fetch` や `each` の説明を変える。説明はRuby 3.4の標準APIを元に同梱した概要とし、全メソッド・全呼び出し形式は網羅しない。挿入するのは従来どおりメソッド名だけで、括弧や引数を自動挿入しない。説明の表示・選択・取消は文書・比較結果・Undo履歴を変更しない。
- カーソルより前の文字で候補を絞り込み、LSPの候補は返された編集範囲、基本候補は識別子全体を置き換える。後続の `!=`・`!~` などの演算子は保持する。
- 定型コードは `if … end`、`items.each do |item| … end`、`gets.split.map(&:to_i)` の3種類。既存の字下げと2スペース単位を引き継ぎ、条件または対象の名前を選択してすぐ書き換えられる。ドットの後のeachは既存の対象を保持する。Tabによる入力欄の移動は設けない。
- 編集・カーソル移動・文書切替・取消で古いLSPの応答を破棄し、別のコードに候補を挿入しない。候補の取得中も同じ制約を適用する。
- コメント・文字列中と日本語変換中には候補を開かない。候補の表示・選択・取消だけでは文書や比較結果を変えず、挿入は通常の編集として扱いUndo／Redoできる。編集禁止になったら候補を閉じ、ファイル・問題の切替で前のファイルの候補を残さない。
- 「検索・置換」またはCtrl+F／Ctrl+Hでエディタ内の検索・置換欄を開く。次／前の一致、個別／全件置換とEscでの終了に対応する。検索だけでは文書・比較結果を変更せず、置換は通常の編集として保存の対象にし、未比較にする。
- Ctrl+ZでUndo、Ctrl+YまたはCtrl+Shift+ZでRedoできる。Windowsでも両方のRedoキーを同じ編集履歴に適用する。履歴はファイルごとに持ち、タブを切り替えても各ファイルの履歴を保つ。問題の切替では履歴をリセットし、前の問題の文書を復元しない。保存では履歴を保つ。
- Ctrl+S・Ctrl+Enterはすぐ保存・実行を優先する。ダイアログ内では既存の抑止を維持する。
- 問題を開くまでと、問題の読み込み中・終了確認中はコードと置換による編集を禁止する。読み取り専用の間もフォーカスを受け取れ、問題を開いた後にコード欄へ戻れる。実行中の編集は既存どおり可能で、古い実行の比較結果を現在の入力へ反映しない。
- 解答ファイルはタブで切り替える。タブの「＋」で追加、右クリックで削除・名前の変更ができる。LFへの改行統一、UTF-8で1 MiBの保存・実行上限、自動保存、問題ごとの解答・サンプル復元を維持する。1280×720の4列配置でエディタ内をスクロールでき、検索欄で実行ボタンを押し出さない。検索欄も高さを制限し、収まらない操作は欄内でスクロールできる。
- JavaScriptとライセンスをビルド時に同梱する。CodeMirrorの表示用CSSはアプリ内で生成し、外部のスクリプト・フォント・サービスを取得しない。補完は[ローカルのRuby LSP](ruby-lsp.md)へ接続し、起動中・失敗時も編集・保存・実行を継続できる。初回の手動補完で起動し、失敗時は基本候補と再試行ボタンを提供する。

候補生成を単体テストで確認する。画面テストで色分け、字下げ、括弧補完・対応表示、入力補完・定型コード、検索・置換、Undo／Redo、履歴分離、日本語入力と自動保存、保存・実行ショートカット、大きな文書・最小画面を確認する。LinuxのChromiumとWindowsのWebView2で共通の受入テストを実行する。

メソッドの引数・説明の参照元は[Ruby 3.4.5の公式ソース内の標準API資料](https://github.com/ruby/ruby/tree/v3_4_5)。String・Array・Hashのよく使うメソッドを対象とする。

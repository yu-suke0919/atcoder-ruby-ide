# MVP 仕様

## 目的

個人が Windows で使う、AtCoder の Ruby コードを編集・実行するデスクトップ IDE を作る。
最初のリリースのゴールは、Ruby コードを編集し、サンプル入力を与えて実行結果を確認できること。

開発は資料更新 → 受入条件のテスト → 最小実装 → 不要コード・資料矛盾の確認の順で行う。
後方互換やデータ移行は設けず、現在の仕様を満たすシンプルな構成を維持する。

## 利用の流れ

1. 起動すると、実行可能なサンプルコードと標準入力が表示される。
2. コードを編集するか、UTF-8 の `.rb` ファイルを開く。
3. 必要に応じてコードを UTF-8 のファイルに保存する。
4. 標準入力を入力し、実行する。
5. 標準出力・標準エラー・終了状態・実行時間を確認する。
6. 終わらないコードは停止でき、停止後も再実行できる。

## 受入条件

| ID | 機能 | 完成の条件 |
| --- | --- | --- |
| M01 | コード編集 | 複数行の Ruby コードを編集でき、Tab で 2 文字のスペースを挿入できる。 |
| M02 | 読み込み | 日本語・空白を含むパスの UTF-8 ファイルを開ける。選択キャンセル時は現在の内容を維持する。UTF-8 BOM は読み込み時に除く。 |
| M03 | 保存 | 初回は保存先を選び、以降は同じパスへ保存できる。「名前を付けて保存」もできる。キャンセル・失敗時は変更状態を維持する。 |
| M04 | 実行 | 標準入力 `1\n2 3\ntest\n` を読むサンプルを実行すると、標準出力に `6 test\n` が表示される。入力は EOF まで渡す。 |
| M05 | 出力 | stdout と stderr を分け、実行中も順次表示する。構文エラー・実行時エラー・Ruby 起動失敗を表示し、その後も実行できる。 |
| M06 | 停止 | 停止操作で実行中のプロセス群を終了し、再実行できる。5 秒を超える実行は自動停止する。 |
| M07 | 実行制御 | 同時実行は 1 件。保存済みファイルはそのディレクトリを作業ディレクトリとし、現在の編集内容を実行する。未保存時は一時ディレクトリを使う。 |
| M08 | 上限 | コード・標準入力はそれぞれ UTF-8 で最大 1 MiB。出力の合計が 1 MiB に達したら打ち切り、停止理由を表示する。 |
| M09 | 変更の保護 | 変更済みのコードを開き直す・新規作成する・ウィンドウを閉じる際、破棄の確認を行う。拒否したら編集内容を維持する。 |
| M10 | Windows 配布 | Windows x64 用のポータブル `.exe` を生成し、Windows 用 Ruby を同梱する。利用者によるアプリのインストールや Ruby の別途インストールを不要にする。 |

標準入力は毎回手入力し、Ruby ソースだけを保存する。改行はそのまま実行に渡す。
コード編集欄は改行を LF に統一する。CRLF のファイルを開いた直後は変更済みとしない。
一時ファイルの削除に失敗しても実行状態は解除し、後続の実行を可能にする。
ショートカットは `Ctrl+O`（開く）、`Ctrl+S`（保存）、`Ctrl+Shift+S`（名前を付けて保存）、`Ctrl+Enter`（実行）。

## 実行環境

- Linux Cloud で通常の開発・Ruby 実行テスト・Electron の画面テストを行う。
- Windows 上で同じテストと配布物の確認を行うため、GitHub Actions の Windows ジョブを用意する。
- 開発環境の Ruby は現在 3.4.12。Windows には公式 RubyInstaller 3.4.12-1 x64 を同梱し、公式サイト用データで公開された SHA-256 に固定する。
- AtCoder 本番と Ruby バージョンや追加 gem が完全に一致することは、今回の MVP の保証範囲に含めない。標準ライブラリを使ったローカル実行を提供する。
- Ruby は通常のユーザープロセスとして実行する。アプリはオンラインのコード実行サービスではない。

## 次のイテレーションの候補

- 複数サンプルの保存と期待出力の比較
- シンタックスハイライトと補完
- AtCoder の問題データの取得
- AtCoder 実行環境とのバージョン・gem の一致
- インストーラー形式の配布とアプリアイコンの整備

優先順位は MVP を使ってから決める。
